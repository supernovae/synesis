# Observability, Verification, and Evals

## Observability Requirements

- structured trace events across deterministic, constrained, inferential, and abstain paths
- decision metadata including active policy/constitution versions
- ambiguity transitions and escalation reasons
- source provenance and evidence confidence markers

## Verification Requirements

- run deterministic checks whenever available
- persist validation outputs for replay and governance review
- record pass/fail confidence and uncertainty classification

## Evaluation Tracks

- **Quality:** task success, correctness, and regression rate
- **Reliability:** false certainty rate, abstain quality, rollback frequency
- **Efficiency:** latency, token usage, cache hit patterns
- **Governance:** policy conformance across clients and teams

## Replay and Audit

Support policy replay against historical traces to evaluate:

- candidate threshold changes
- constitution updates
- source ranking adjustments
- client-adapter conformance
