# Synesis documentation

Synesis provides local source packs and four read-only MCP knowledge tools. These guides describe the implemented path:

- [Source packs](SOURCE_PACKS.md): format, build/import/search/read commands, saved HTML, integrity and recovery.
- [MCP setup](clients/MCP_QUICKSTART.md): launch the reader from a client.
- [Client boundaries](clients/CLIENTS.md) and [harness compatibility](clients/HARNESS_COMPATIBILITY.md): explicit libraries, client-owned execution and limits of verification.
- [Model compatibility](model-compatibility.md): native protocols and architecture-specific serving considerations.
- [Security boundaries](SECURITY.md) and [reporting policy](../.github/SECURITY.md).
- [Contributing](../CONTRIBUTING.md): local development and checks.
- [Architecture decisions](ARCHITECTURE_REVIEW.md) and [recorded evidence](../evals/architecture/README.md): rationale, completed work and unresolved product-fit questions.

Planner, Yarn, Admin, their shims and deployment recipes are removed. Historical inventories and research are evidence of earlier work, not installation guides or current support commitments. Git history retains the retired implementations.

The local reader is usable from a checkout. No registry release, hosted service, universal client certification or model-quality advantage is claimed.
