# Yarn Agent Runtime (Python — retired)

The Python Yarn runtime (`base/yarn/`) has been removed. The TypeScript runtime (`base/yarn-ts/`) is the sole supported Yarn implementation.

The historical Python-era documentation is preserved at [`docs/deprecated/YARN_RUNTIME.md`](./deprecated/YARN_RUNTIME.md).

For current runtime documentation, configuration, and deployment, see the [`base/yarn-ts/` README](../base/yarn-ts/README.md).
